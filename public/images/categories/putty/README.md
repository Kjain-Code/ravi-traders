# putty — real photos yahan daalein

1. Apni product photo is folder mein copy karein (jaise `product-name.jpg`).
2. `frontend/src/data/products.js` mein us product ka `image` field update karein:
   ```
   image: "/images/categories/putty/product-name.jpg",
   ```
3. Save karke refresh karein — nayi photo dikhne lagegi.

Filhaal is folder mein sirf placeholder.jpg hai (dummy image), jab tak
tum apni real photo nahi daalte.
